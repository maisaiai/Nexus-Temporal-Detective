# Nexus Temporal Detective

Et projekt under opbygning med tidsbaseret detektivarbejde som foreløbigt udgangspunkt: undersøg sager, forbind spor og rekonstruér hændelser på en tidslinje.

Projektets navn er udgangspunktet for denne startstruktur. Spilformat, historie, platform og teknisk løsning er endnu ikke besluttet. Der er ingen kørende prototype endnu.

## Kom i gang

1. Læs [projektretningen](docs/concept.md), og tilpas den til din idé.
2. Kopiér [sagsskabelonen](content/cases/_template.md) til en ny Markdown-fil i samme mappe.
3. Beskriv én lille sag med tre spor og en tydelig løsning.
4. Afprøv sagen på papir, før du vælger teknologi og bygger en prototype.

Du kan redigere filerne direkte på GitHub. Ingen installation er nødvendig for at arbejde med konceptet.

## Struktur

| Mappe | Indhold |
| --- | --- |
| `docs/` | Projektretning og første milepæl |
| `content/cases/` | Sager, spor og tidslinjer |
| `src/` | Fremtidig implementering |
| `assets/` | Egne eller korrekt licenserede billeder, lyd og andre ressourcer |

## Arbejdsform

- Hold første version lille: én sag, én tidslinje og én løsning.
- Brug korte, beskrivende filnavne med små bogstaver og bindestreger.
- Lav små commits med en beskrivelse af ændringen.
- Gem ikke adgangskoder, tokens eller personlige oplysninger i repositoryet.
- Tilføj kun værktøjer og afhængigheder, når en konkret prototype kræver dem.

Der er endnu ingen valgt softwarelicens.
